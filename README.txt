# Chain Genius Consulting website

## Files
- `index.html` — Home
- `services.html` — Services
- `industries.html` — Industries
- `technology.html` — Supply Chain Intelligence Engine
- `insights.html` — Insights and case-study themes
- `about.html` — About Chain Genius Consulting
- `contact.html` — Contact
- `styles.css` — Shared styling and responsive layout
- `script.js` — Shared navigation, scroll progress and reveal effects

## Install
1. Back up your existing website folder.
2. Copy these files into the root of the existing website, replacing the old `index.html` only after backing it up.
3. Keep your existing `applications/` directory unchanged.
4. Confirm that `./applications/inventory-intelligence-engine/` is still the correct path. The technology page links to that existing path.
5. Open `index.html` locally to test, then publish the updated files to your existing GitHub Pages site.

## Notes
- No frameworks, build tools, paid services, external fonts or APIs are required.
- The navigation is multi-page: each menu item opens a separate HTML page.
- The contact page currently links to the existing LinkedIn business page. It does not pretend to submit a form; add a form only when a real receiving method/backend is configured.
- The CG text mark is a placeholder. Replace it with the existing Chain Genius logo asset when available.
- Industry coverage and engine capabilities are described carefully as intended scope/development direction, not as claims that all functionality is already released.
- Pricing is intentionally not published yet.
