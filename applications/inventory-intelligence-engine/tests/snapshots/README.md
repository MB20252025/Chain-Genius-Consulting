## Permitted differences for the historical golden snapshots (added 16 Nov 2026, Stage 3, owner decision D1)

`permitted-differences.json` lists, one by one, the 20 changes that N1 makes to Northstar's feasibility results: for each order
(SIM17, SIM18, SIM30–SIM37, SIM39–SIM41, SIM43, SIM45–SIM50), the original delay text ("Likely: ~-N d"), the new text
("No delay if ordered today (arrives ~N d before start)") and the reason. `compare-snapshots.js` applies them to its in-memory copy of
`v0.5-golden-20261105T101953Z.json` and `v0.6.0-baseline-20261109T152050Z.json` only, and prints how many it applied. Both golden
files are unchanged on disk. A listed change that does not match exactly, a negative delay coming back, or any other difference
still fails the comparison. Owner approval: D1 option A, 16 Nov 2026; implemented and technically verified by Claude; Stage 3 not
yet formally accepted.
