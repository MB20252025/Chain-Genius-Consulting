# Inventory Intelligence Engine v0.6

Runs entirely in the browser: open `index.html` (or serve the folder with GitHub Pages). Nothing is uploaded anywhere.

- `index.html` page shell
- `css/styles.css` styles
- `js/calculations.js` analysis, MRP, feasibility, client questions
- `js/forecasting.js` demand forecasting
- `js/app.js` interface and tabs
- `js/excel-import.js` Excel import and export
- `assets/xlsx.mini.min.js` SheetJS (Apache-2.0), bundled so no CDN is needed

All figures are calculated locally. Demonstration data is fictional.
