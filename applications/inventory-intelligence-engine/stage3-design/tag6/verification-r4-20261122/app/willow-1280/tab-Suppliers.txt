Risk: 75+ Low, 60–74 Medium, under 60 High. Only POs received by the snapshot (2026-09-30) are scored; others count as outstanding. Each metric uses only the received lines whose own inputs are valid: on-time and lateness need a valid promised date, lead-time stability needs valid order and received dates, fill rate needs valid numeric quantities (a blank, text, negative or zero-ordered quantity is unknown, not zero; numeric text such as "120" is not converted and is flagged in Data quality). If any of the four metrics has no valid line the overall score is not calculated and the supplier is shown as Not Assessed — Insufficient Evidence; the metrics that can still be assessed are shown. Evidence: Adequate = at least 10 valid lines behind every metric; Limited = fewer; None = at least one metric has no valid line. A Data problem is not a performance classification, and the supplier's materials still count in risk. Assessment separates a performance problem (score under 60 with adequate evidence) from a possible problem on limited history.
