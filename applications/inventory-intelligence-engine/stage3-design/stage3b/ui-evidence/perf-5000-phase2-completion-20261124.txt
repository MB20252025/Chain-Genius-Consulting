## Regressions found and fixed during this work (before the fixes, same machine)
- Safety stock & reorder points 340-401 ms: the S15 'Why' text was built for all 5,000 items on every draw. Fixed: table cells and the text are built only for the rows a screen draws.
- every screen ~25 ms slower: policy rows were built with Object.create(engine row); V8 then slowed every later read of the engine rows (source() 13.6 -> 36.2 ms). Fixed: plain copies.
- the chart-label width was read after the page was rewritten (forced layout each draw). Fixed: read before.
