# Visual references (supplied by the owner, 23 Nov 2026)

- `reference-1-primary.webp`: the **primary** design direction. It shows the dark navy sidebar with the utility links set below a divider, the navy header, colourful KPI cards, the health-score ring, the forecast with a confidence band, risk pills, horizontal supplier bars, numbered recommendations, and a status strip with warehouse imagery.
- `reference-2-supplementary.webp`: **supplementary** inspiration. It shows the hero banner, KPI cards with sparklines, the inventory-health donut, alert cards and financial-impact cards.

These images were generated for the owner as **visual references only**.
- Every company, supplier, product name and figure in them is illustrative. None of it is SCIE data, and none of it may appear in the application or the engine.
- They are not application assets and are not loaded by the application. They are kept here so the design can be checked against them.
- Elements in them that the engine cannot support truthfully are **not** reproduced:
  - trends over time ("Inventory Trends", "Performance Trends", sparklines): the workbook is a single snapshot;
  - "vs last week" deltas;
  - "Live Data";
  - user avatars and notifications;
  - "service level", which the engine does not calculate.
